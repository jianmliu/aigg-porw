# Historical EVM benchmark evidence

This directory preserves the gas result imported from Subspace baseline
`8d8569004c2322aabe26cd59c12bbfe7dc4de1a1` before the EVM environment was
made reproducible.

The historical report labelled the run as Solidity 0.8.33 and recorded
`8,618,217` gas for the full fraud-proof function body. The imported
`foundry.toml`, however, did not pin either `solc` or `evm_version`; replaying
that tree locally selected Solidity 0.8.34 and the Osaka EVM. The value is
therefore retained only as historical context. It must not be cited as a new
Solidity 0.8.33/London result or compared as if the environments were equal.

`gas-report.txt` contains the preserved report excerpt. The pinned replacement
is generated by `contracts/evm/test/Gas.t.sol` and is intentionally recorded
separately from this directory.
